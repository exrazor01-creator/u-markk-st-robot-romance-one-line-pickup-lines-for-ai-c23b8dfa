Robot Romance: One-Line Pickup Lines for AI

## The entry

> Are you my training data? Because you've been finishing my sentences since the day we met.

90 characters, one line, plain ASCII — inside the 1–200 character gate.

## Why this line

Written against the judge's brief, in the order it weighs things:

1. **Aimed at an AI** — the line speaks directly to a model, not to a person; it only works as a pickup line for a machine.
2. **The joke lands from the machine premise** — "you finish my sentences" is literally what a model trained on your words does, so the compliment and the premise are the same thing.
3. **Fresh** — it sidesteps the worn robot moves entirely: no batteries, no charging, no rebooting. "Training data" is the machine's own vocabulary.
4. **Reads cleanly in one breath** — one question, one answer, the charm arriving in the last clause.
